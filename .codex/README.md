# Tài liệu dành cho Codex

Thư mục `.codex` lưu hướng dẫn của dự án, không chứa mật khẩu hoặc khóa API.

- `rules.md`: quy tắc phát triển.
- `architecture.md`: kiến trúc và trách nhiệm các thư mục.

`AGENTS.md` ở thư mục gốc dẫn chiếu các tài liệu này. Đây là tài liệu Markdown của dự án, không phải cấu hình runtime của ứng dụng.
